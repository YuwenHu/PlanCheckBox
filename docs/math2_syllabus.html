3取舍策略（本版怎么砍）

时间不够时按「先砍 P1 → 再减真题套数 → 最后才动科目配比」的顺序处理。

  • 起点按真实进度：函数与极限只补「间断点」之后的判定与题型，导数从定义开始；不回头重学函数性质。
  • 每章一次过关测试：直接抽真题 15 题（45 分钟），正确率 <70% 不进下一章；测试与刷题合并，数二真题总时长相应下调 8.25 小时。
  • 每次测试后 3 天内排 45 分钟「机动·重测/订正」（共 11 次 = 8.25 小时），只从缓冲时段支出，不挤占任何科目的 P0。
  • 顺序：2026-11-05~12-31（间断点→导数→中值定理）→ 2027-01~04（一元积分＋行列式/矩阵）→ 2027-05~07（线代收尾＋多元/二重/微分方程）→ 2027-08~10-19（强化＋真题 2018-2022）→ 2027-10-20~12-19（真题 2023-2026）。
  • 真题只做 2018-2026 共 9 套，不排全套历史；2016-2017 留 2 套作 P1，本次已排入 2027-10-20 ~ 12-19。
  • 词汇释放的小时里约 82.2 小时追加给数二的 P1：2027-08-01~10-19 的证明题二轮（中值定理与不等式）与高数错题回炉，2027-10-20~12-19 的 2018-2026 真题错题重做，2026-11~12 与 2027-01~04 的基础题型补练。
  • P2（凹凸 / 渐近线、多元条件极值）仍未排（可弃）；模拟卷 3 套、早年真题 2016-2017 已全部排入。
  • 本版新增约 86.3 h 的 P1（来自词汇释放额度）：证明题专练、错题回炉、真题二刷、模拟卷；逐日追加在晚上与周末下午的缓冲时段。
    • 本次未排（被砍）合计：全科 P1 19.3 h、P2 0.0 h、P0 0.0 h。P0 已 100% 排入，P1 只排了 353.9 h。
